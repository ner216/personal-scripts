# Scripts

- `extract` : (Generated via Gemini) Extracts gresource binary files. (These files are used to compress GTK themes)

- `configure_ubuntu*` : Initial setup configuration helper script for Ubuntu. This script has features such as hiding the ~/snap directory, replacing the snap store with gnome-software, etc.

- `set-fan` : Sets fan control to manual or auto on desktop Nvidia GPUs.

- `thermal-mode` : Changes platform-power-profile for Dell Laptops.
